# 연서 사이트

소개팅 앱 「연서」의 소개, 개인정보 처리방침, 이용약관, 지원 페이지. `docs/` 폴더를 깃허브 페이지로 게시한다.

주소: https://bbdyno.github.io/Yeonseo-Site/

색, 글꼴, 부품 값은 앱 시안과 같다. 검정 바탕, 흐린 브론즈 배경 위 유리판, 금속 금(`#E7CD7A`, `#D2BA73`, `#95814F`), 마루 부리 명조 제목, 프리텐다드 본문, 금색 월계관 배지. 월계관 그림(`docs/img/laurel-*.svg`)은 시안의 그리기 함수로 미리 만들어 둔 정적 파일이다.

정적 HTML과 CSS만 쓰고 빌드 단계는 없다. 로컬에서 볼 때는 `python3 -m http.server --directory docs`.
